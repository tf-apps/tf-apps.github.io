Datenschutzerklärung

Diese Datenschutzerklärung gilt für die iOS-App BikePass, entwickelt von TF Apps.

Der Schutz deiner persönlichen Daten ist uns wichtig. Diese Erklärung informiert dich darüber, welche Daten die App verarbeitet und wie sie gespeichert werden.

1. Datenspeicherung – Übersicht

📱 Basic (kostenlos)

  • Nur lokal auf dem Gerät
  • Keine Cloud
  • Keine Server
  • Vollständig offline

⭐ Premium

  • Lokal auf dem Gerät
  • Optional: iCloud Backup
  • Keine eigenen Server
  • Du hast die Kontrolle

Folgende Daten können gespeichert werden:

  • Fahrradinformationen (Marke, Modell, Rahmennummer etc.)
  • Fotos deiner Fahrräder
  • Persönliche Kontaktdaten (Fahrzeughalter)
  • Hochgeladene Dokumente (Rechnungen)
  • Kaufinformationen, Leasing-Daten und Notizen

Diese Daten verlassen dein Gerät nur, wenn du aktiv eine Exportfunktion verwendest oder iCloud Backup aktiviert hast.

2. iCloud Backup Premium

Premium-Nutzer können optional das iCloud Backup aktivieren. Dies ermöglicht die sichere Sicherung und Wiederherstellung aller Daten – auch nach Neuinstallation oder Gerätewechsel.

☁️ Bei aktiviertem iCloud Backup werden deine Daten in deiner persönlichen iCloud gespeichert. TF Apps hat keinen Zugriff auf deine iCloud-Daten. Die Daten gehören ausschließlich dir.

Was gesichert wird:

  • Alle Fahrraddaten und Einstellungen
  • Fotos deiner Fahrräder
  • Hochgeladene Dokumente
  • Dein Nutzerprofil (Fahrzeughalter-Daten)

Wichtige Hinweise:

  • iCloud Backup ist standardmäßig deaktiviert
  • Du kannst es jederzeit in den App-Einstellungen aktivieren oder deaktivieren
  • Die Synchronisation erfolgt über Apple's CloudKit
  • Es gelten zusätzlich die Datenschutzbestimmungen von Apple
  • Deine iCloud-Daten kannst du unter iOS-Einstellungen → [dein Name] → iCloud löschen

3. Keine eigenen Server

TF Apps betreibt keine eigenen Server und hat keinen Zugriff auf deine Daten. Es gibt:

  • Keine Registrierung oder Benutzerkonten bei TF Apps
  • Keine Analyse- oder Tracking-Tools
  • Keine Werbung oder Werbe-Netzwerke
  • Keine Datenweitergabe an Dritte

4. In-App-Käufe

BikePass bietet einen optionalen Premium-Kauf (einmalig 2,99 €) an. Dieser wird vollständig über Apple's In-App-Purchase System abgewickelt. TF Apps hat keinen Zugriff auf deine Zahlungsinformationen.

5. Berechtigungen

📷 Kamera & FotosFür Fahrradfotos
📁 DateizugriffFür Dokument-Upload (Premium)
☁️ iCloudFür Backup (Premium, optional)

6. Datenlöschung

  • Einzelne Daten: Direkt in der App löschbar
  • Alle lokalen Daten: App deinstallieren
  • iCloud-Daten (Premium): iOS-Einstellungen → [dein Name] → iCloud → BikePass

⚠️ Bei Deinstallation ohne aktives iCloud Backup werden alle Daten unwiderruflich gelöscht.
